"@klank/sdk": minor
---

- New subpath `@klank/sdk/testing`: `MockKlank`, an in-process Klank fake (real HTTP + WebSocket on a random port, single-use tickets, recorded requests, `deliver()`/`respond()`/`waitForRequest()`) for testing bots without a server.
- `CommandInvokedEvent` carries `bot_id`, matching the server's `command.invoked` event.
- Wire-fixture drift gate: `fixtures/wire/server-events.json` is generated by the server and checked against `src/types.ts` in CI (`scripts/sync-wire-fixtures.sh` refreshes it).
- Docs track the server bot-model work: bot channel membership (`POST /channels/{cid}/bots`), bot tokens on message routes, slash command registration and delivery, and the `bot-ws-ticket` fix.
