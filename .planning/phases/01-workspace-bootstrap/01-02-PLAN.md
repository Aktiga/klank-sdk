Key notes:
- `"type": "module"` — ESM-only per CONTEXT deferred ideas (dual CJS/ESM deferred).
- `"main"` and `exports.import` both point at `./dist/index.js` (ESM `.js` under `"type": "module"`).
- `"types"` points at `./dist/index.d.ts` — emitted by `tsc -b`, not `tsup`.
- `build` script first runs `tsc -b tsconfig.build.json` (emits `.d.ts` only), then `tsup` (emits `.js` only). Both land in `dist/`. tsup has `clean: false` so it does not delete the `.d.ts` files.

Create `packages/sdk/tsup.config.ts` with exactly:

```ts
import { defineConfig } from 'tsup'

export default defineConfig({
  entry: ['src/index.ts'],
  format: ['esm'],
  target: 'node20',
  outDir: 'dist',
  dts: false,
  clean: false,
  sourcemap: true,
  splitting: false,
  treeshake: true,
})
```

Rationale (per RESEARCH §1): `dts: false` because `tsc -b` owns declaration emission under project references. `clean: false` because tsup runs AFTER tsc — cleaning would delete the just-emitted `.d.ts` files.
